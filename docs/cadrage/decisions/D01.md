# D1 — Unité d'analyse : le compte client B2B

*Atelier de cadrage n°1.*

## Décision

L'unité d'analyse est le **compte client B2B** (`client_id`), jamais une personne physique.

## Justification

C'est le grain du jeu de données ; cela cadre la finalité RGPD sur une entité contractante.

## Où elle est appliquée

- Tout le pipeline raisonne au compte : une ligne = un compte ([notebook](../../../reports/notebooks/notebook_certifiant_churn_saas.ipynb), §2.4).
- Le portique RGPD vérifie l'absence de données identifiantes avant toute ingestion ([RGPD et éthique](../../donnees/rgpd_et_ethique.md)).

## Statut

Appliquée.
