# D14 — Règle de priorité

*Point de contact métier n°3.*

## Décision

**Haute** = comptes signalés (score ≥ seuil [D9](D09.md)) triés par perte attendue décroissante, dans la limite de 150 ([D10](D10.md)) ; **Moyenne** = signalés restants ; **Basse** = non signalés. Perte attendue = score de churn × valeur vie estimée.

## Justification

Concentrer la capacité CS sur les plus gros enjeux économiques parmi les comptes à risque.

## Où elle est appliquée

- [`assigner_priorites`](../../../src/scoring.py) ; le rang de perte attendue est repris dans l'explication de chaque décision.
- Conséquence assumée : un compte de très grande valeur mais sous le seuil n'entre jamais dans la liste (notebook, §10.2 et §12.4).

## Statut

Appliquée. Une évolution est proposée au métier : un **filet de sécurité** qui ferait passer en Moyenne les comptes sous le seuil dont la perte attendue dépasse celle du 150ᵉ compte Haut.
