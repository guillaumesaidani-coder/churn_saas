# D14 — Règle de priorité

*Point de contact métier n°3.*

## Décision

**Haute** = comptes signalés (score ≥ seuil [D9](D09.md)) triés par perte attendue décroissante, dans la limite de 150 ([D10](D10.md)) ; **Moyenne** = signalés restants, plus les comptes du **filet de sécurité** ; **Basse** = les autres. Perte attendue = score de churn × valeur vie estimée.

**Filet de sécurité** (adopté le 2026-10-03) : un compte sous le seuil passe en Moyenne si sa perte attendue dépasse celle du dernier compte Haute du lot. Ce seuil se recalcule à chaque lot scoré.

## Justification

Concentrer la capacité CS sur les plus gros enjeux économiques parmi les comptes à risque.

Le filet bouche un trou de la règle d'origine : un compte très précieux mais juste sous le seuil n'entrait jamais dans la liste. Exemple du cycle de test : CLI-003986, score 0,253 (seuil 0,283), perte attendue 81,9 k€ contre 5,3 k€ pour le 150ᵉ compte Haute, parti avec une perte réelle de 403 k€.

| Cycle de test (1 000 comptes) | Sans filet | Avec filet |
|---|---|---|
| Comptes en Moyenne (email) | 215 | 350 |
| Comptes partis à forte perte* couverts (Haute ou Moyenne) | 56 / 70 | 64 / 70 |
| Part de la perte réelle couverte (Haute ou Moyenne) | 86 % | 95 % |
| Appels CSM | 150 | 150 |

\* les 25 % de comptes partis à la plus forte perte réelle (≥ 25 k€).

Le filet vise la valeur, pas le risque : 9 des 135 comptes ajoutés sont partis. L'email coûte peu, et c'est une action commerciale, pas un droit dont les petits comptes seraient privés. Sur le portefeuille complet (cycle simulé de 5 000 comptes), le filet n'ajoute que **38 comptes** : le 150ᵉ compte Haute y a une perte attendue bien plus élevée (71 k€). Le filet a été conçu après lecture du test : son effet sera confirmé au premier cycle réel ([D15](D15.md)).

## Où elle est appliquée

- [`assigner_priorites`](../../../src/scoring.py) (colonne `filet_D14`, désactivable avec `filet_d14=False`) ; le rang de perte attendue est repris dans l'explication de chaque décision, et l'explication d'un compte du filet le dit ([`expliquer_decision`](../../../src/explain.py)).
- Le filet s'applique aussi à l'API, qui appelle la même fonction.
- Notebook (§10.2, §12.4) : mis à jour au lot 4, avec le rejeu officiel.

## Statut

Appliquée, filet compris (2026-10-03). Tests : `tests/test_scoring.py::TestFiletD14`.
