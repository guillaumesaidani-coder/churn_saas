# D3 — Le modèle priorise, il ne décide pas

*Atelier de cadrage n°1.*

## Décision

Le modèle **priorise** ; aucune action n'est déclenchée automatiquement.

## Justification

Article 22 du RGPD (pas de décision fondée exclusivement sur un traitement automatisé) ; condition d'adoption par les CSM.

## Où elle est appliquée

- [`src/scoring.py`](../../../src/scoring.py) : `action_est_conforme_d3` rejette toute formulation d'action exécutée sans intervention humaine ; testé par [`tests/test_scoring.py`](../../../tests/test_scoring.py) (`TestConformiteD3`).
- Vérifié dans le notebook (§4, §10.2) et dans ses vérifications finales (§15.3).
- Chaque priorité est livrée avec son explication, pour que le CSM puisse la contester ([lire une explication](../../explicabilite/lire_une_explication.md)).

## Statut

Appliquée et testée automatiquement.
